                         # CSP451 CheckPoint 1

This project was created for Week 1 of CSP451 to demonstrate the fundamentals of Git and GitHub version control. It includes basic web development files and showcases standard Git workflows such as commits, branching, and pull requests.

                          # Installation

1. Clone the repository using Git: https://github.com/nbajagain/CSP451-CheckPoint1-Nawaraj-Bajagain/edit/main/README.md
2. Navigate to the project folder.
3. Open `index.html` in a web browser.

                          # Usage

When the page loads, a message will be displayed in the browser console to confirm that the file is working correctly.
